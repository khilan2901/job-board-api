# Job Board API

A backend REST API built with Node.js, Express, and MongoDB.

## Tech Stack
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication (in progress)
- BullMQ + Redis for background jobs (planned)

## Completed
- Project architecture and folder structure
- Database schemas: User, Company, Job, Application
- Mongoose indexes, hooks, and validations
- Global error handling middleware

## In Progress
- CRUD routes for Jobs and Companies
- File uploads with Cloudinary
- Email notifications with BullMQ
